응답의 `review`에는 프로필이 정한 칸만 들어 있습니다. 프로필은 리뷰를 부를 때마다 붙이던 옵션의 기본값을 사람마다 정해 두는 파일입니다. 이 스킬의 기본값은 `audience`가 `peer`, `postVerdict`가 `true`, `approveWhenNoBlocking`이 `false`입니다.

명령은 `GESTALT_HOME`까지 풀어서 홈의 `.gestalt/profile.json` 하나만 읽습니다. 리뷰 대상 레포의 `.gestalt/` 아래 파일도 안 봅니다. `approveWhenNoBlocking`은 리뷰어 계정으로 승인을 내보내는 값이라 리뷰받는 쪽이 심어 둔 파일로 켜지면 그 레포가 내 승인을 내게 됩니다.

`warnings`에 걸린 칸은 응답에서 이미 빠져 있습니다. 경고를 그대로 옮기고 그 칸은 기본값으로 진행합니다. 명령 자체가 실패했으면(런처가 버전을 못 맞췄거나 응답이 JSON이 아니면) 그 사실을 아래 줄에 적습니다.

**어떤 값이 프로필에서 왔는지 리뷰 시작 보고에 한 줄로 밝힙니다.** 0단계 질문 묶음 맨 위에 붙입니다. 0단계를 건너뛰면 1단계를 시작한다고 알리는 첫 메시지에 붙입니다. 이 줄은 0단계 전체 건너뛰기에 함께 걸리지 않습니다. 4.7단계 `게시 준비`에서 처음 읽었으면 게시 확인 미리보기 위에 붙입니다.

```
프로필에서 가져온 값: audience=junior, approveWhenNoBlocking=true (postVerdict는 호출 인자가 덮었어요)
```

프로필이 정한 값도 경고도 없으면 이 줄을 생략합니다. 프로필이 없는 사람에게는 지금과 똑같이 보여야 해서요. 파일 꼴은 `{ "review": { "audience": "junior", "approveWhenNoBlocking": true } }`이고 사용자가 손으로 만듭니다. 이 스킬은 파일을 쓰지 않습니다.

**`audience`가 프로필에서 왔으면 그 사실을 기억해 둡니다.** 대상이 로컬 PR이면 1.05단계가 이걸 보고 묻지 않고 `peer`로 내립니다. 프로필은 이번 호출에 준 옵션이 아니라 모든 리뷰에 미리 정해 둔 기본값이라 로컬 PR에서 안 먹는 게 예상된 일입니다. 거기서 매번 물으면 ship처럼 `--audience` 없이 이 스킬을 부르는 쪽에 없던 멈춤이 라운드마다 생깁니다. 내릴 때는 아래 줄로 알립니다.

```
프로필의 audience=junior는 로컬 PR에 적용되지 않아서 peer로 진행해요.
```
